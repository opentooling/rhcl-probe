rhcl-probe is installed in {{ .Release.Namespace }}. Its routes attach to {{ .Values.gateway.namespace }}/{{ .Values.gateway.name }} as {{ .Values.gateway.hostname }}.

1. The gateway only accepts routes from labelled namespaces. On the RHCL platform:

   oc label namespace {{ .Release.Namespace }} api-gateway-access=true

2. Open the console:

   oc port-forward -n {{ .Release.Namespace }} svc/{{ include "rhcl-probe.fullname" . }}-console 8080:8080

   then browse to http://localhost:8080 and choose "Run all".

3. Or run the whole suite from the command line; it fails if any check fails:

   helm test {{ .Release.Name }} -n {{ .Release.Namespace }} --logs
